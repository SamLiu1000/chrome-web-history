# 浏览历史记录 · Web History Archive

一个独立于 Chrome 自带历史记录的、**本地化、可搜索、可整理、可备份**的个人长期浏览记录库（Chrome 扩展，Manifest V3）。

定位：**帮助用户记录和整理好历史浏览记录**，而不是数据分析工具。

- 所有数据只保存在本机扩展自有的 IndexedDB 中，**无服务器、无上传、无任何外部请求**（连 favicon 都不联网获取）。
- 不受 Chrome "自动清理 90 天历史" 的影响，目标保存 5～20 年。
- 零依赖、零构建：纯原生 JavaScript，`chrome://extensions` 加载即用。

## 安装（开发者模式加载）

1. 打开 Chrome，访问 `chrome://extensions`
2. 右上角开启 **开发者模式**
3. 点击 **加载已解压的扩展程序**，选择本目录（包含 `manifest.json` 的文件夹）
4. （可选）把扩展图标固定到工具栏

> 权限说明：`history`/`tabs` 用于记录访问（写入扩展自有的隔离存储，不读取也不修改 Chrome 历史数据库）；`storage` + `unlimitedStorage` 保证长期大数据量不被清理；`sidePanel` + `contextMenus` 用于垂直标签栏（打开/关闭均由用户主动触发）；`favicon` 读取 Chrome 本地图标缓存。

## 功能

### 浏览（主视图）
- **扁平单行时间线**：`时间 | ★ | 标题 + 网址 | 访问方式 | 删除`，按时间排列，无多余留白
- 筛选：今天 / 昨天 / 近 7/30/90 天 / 今年 / 全部 / 自定义起止；多域名筛选；标题与 URL 关键词搜索；**只看收藏**
- 点击行内网址可快速把该域名加入筛选
- **"站点"视图**：同一主地址的记录汇总成可折叠文件夹（类似旧版 IE 的历史侧栏）
- 单条记录可直接删除

### 收藏
- 任何网址点击 ★ 收藏 / 取消收藏（浏览列表和站点文件夹里都可以）
- "只看收藏"一键过滤出所有收藏的网址

### 站点（按主地址整理与统计 · 浏览页内切换）
- 顶层导航只有 浏览 / 标签页 / 设置；浏览页顶部的"历史记录 | 站点记录 | 书签"切换按钮（侧栏"📁 按站点浏览"按钮同样可切换到站点记录），选择会被记住
- 所有域名按**主地址**聚合：`mail.qq.com`、`www.qq.com` → `qq.com` 文件夹
- 层级展开：站点 → 网址（含收藏、访问次数、最后访问时间）→ 每次访问的时间明细
- 排序：按累计访问量 / 按最近访问 —— 这也是按站点统计的入口

### 书签管理（浏览页内切换 · 与 ★ 收藏同源）
- 浏览页顶部切到"书签"即进入：左栏**文件夹树**（可折叠，书签视图下已加宽），右栏当前文件夹的子文件夹与书签
- 管理 Chrome 原生书签树（`chrome.bookmarks`）：新建子文件夹、重命名（书签可同时改网址）、删除（文件夹含内容，有确认提示）、**拖拽移动**（书签/文件夹拖到树的任意文件夹，禁止拖进自身子级）
- **批量选择与转移**：条目可勾选（全选/反选），批量**复制/移动**到任意文件夹（树形选择目标，自动禁止移入自身子级；文件夹整棵递归复制）
- **替换域名**：把旧域名（含子域名）的书签批量指向新域名，路径保持不变，子域名前缀自动保留（`mail.old.com → mail.new.com`）；可全局或仅当前文件夹（含子文件夹）生效，替换前显示匹配数量并确认
- 搜索书签（标题/网址），结果平铺显示并标注所在路径；"打开全部"一次打开当前文件夹的所有书签
- **HTML 导入**：支持 Chrome/Edge 书签管理器"导出书签"生成的标准书签 HTML 文件，整棵文件夹树导入到书签栏下自动新建的"导入的书签 <时间>"文件夹，单条失败不影响整体；**自动识别文件编码**（UTF-8 / UTF-16 / GB2312·GBK 等按声明与字节特征探测），老浏览器导出的 GB2312 文件不乱码
- 与浏览页的 ★ 收藏、添加书签对话框操作的是同一份数据，不会出现两套书签

### 自动记录
- 每次真实导航自动记录：URL、标题、域名、精确访问时间、访问方式（地址栏输入/链接点击/刷新/表单提交等）、标签页 ID

### 垂直标签栏（标签页接管）
- **右键扩展图标 →「开启/关闭垂直标签栏」**：一个开关搞定——开启即打开侧栏（Chrome Side Panel）接管，关闭即收起侧栏；开关状态会记住。侧栏收起后浏览器就是普通界面，不残留任何东西
- 垂直列表完整接管标签页管理：**点击切换**、× / 中键**关闭**、📌**固定/取消固定**（固定标签置顶）、**静音**（悬停显示；正在发声的标签常显 🔊，已静音常显 🔇）、**拖拽排序**（可拖入/拖出固定区、跨窗口拖动）
- **实时同步**：开/关/标题/加载状态全部由 Chrome 标签页事件驱动（无轮询），几百个标签也流畅
- **搜索过滤**：按标题或网址即时筛选打开的标签页
- 多浏览器窗口自动分组显示（聚焦窗口优先，隐身窗口有标注），另有**新建标签页**按钮
- 位置说明：Chrome 不允许扩展指定侧栏左右，首次使用可在侧栏图标右键选择"移到左侧"，之后会记住

### 标签收纳（OneTab 式 · 独立页签）
- **左侧文件夹管理栏**（对齐 OneTab 的左栏）：主列表 / 文件夹树（可嵌套、可新建子文件夹、重命名、删除）/ 回收站（带计数）；分组可"移动到文件夹…"，收纳时进当前所在文件夹
- **收纳当前窗口 / 全部窗口**的标签页为一组（自动去重、只收 http/https、保留固定置顶），腾出浏览器窗口
- 标志性交互与 OneTab 一致：**整组恢复**（新窗口打开，原组进回收站可找回）、单条点击打开、**锁定分组**（防整组误删）、**星标**、**置顶标签**、**点击组头任意空白处折叠/展开**、**命名 + 备注**
- 所有输入与确认（重命名、备注、新建文件夹、删除确认等）均为**页面内对话框**，不使用浏览器原生弹窗
- **组 "⋯" 菜单**：单组导出 HTML（OneTab 同款模板）、复制为"标题+网址"文本 / Markdown、移动到文件夹、重命名/备注、锁定、移入回收站
- **标签行**：✎ 单条备注（导出 HTML 与复制时带上）、📌 置顶、× 删除
- **编辑模式**：多选分组，批量"移入回收站 / 移动到文件夹"，支持全选/反选
- **导入文本**：粘贴任意文本（网页列表、笔记、其它工具导出的文本），自动提取 http(s) 链接收纳成组，行内"标题 网址"格式可保留标题
- **回收站**：删除的分组暂存，可单独恢复或清空
- **与 OneTab 2.21 数据完全兼容**：数据结构即 OneTab 的 item 树；"导出 JSON"生成 `onetap-full-backup` v2 格式，可直接导入 OneTab 的备份与同步页，反之 OneTab 导出的 JSON 也能导入本扩展（导入会替换本机收纳数据并自动暂停云同步，确认无误后手动同步一次即可推送）
- **导出 HTML**：与 OneTab "保存为 HTML 文件" 同款模板与样式（支持全部或单组导出）

### 云同步（标签收纳 + 书签 · 可选）
- 自建 Cloudflare Worker + D1（免费），多台设备间同步**标签收纳数据与书签**；**浏览历史不参与同步、绝不出本机**
- **安全默认：自动同步仅下载**——只把云端其它设备的数据合并到本机，本机数据不上传；上传需要明确动作：「同步云」按钮（↑ 上传到云）、勾选"自动双向"开关（有确认警告）、或点最右侧"双向同步"（每次都有确认对话框）。「同步本地」（↓ 下载到本机）永远不会改动云端快照
- 端到端加密：数据 gzip + AES-GCM 加密后上传，服务器只见密文（PBKDF2 250000 次派生密钥，口令不经过服务器）
- **多版本快照**：每次上传在云端产生新版本（每设备保留最近 10 版），绝不覆盖历史，误同步可回滚
- 多设备合并：快照式按 `id + modifyDate` LWW 合并，删除走 tombstone 传播（防"删除复活"）；书签为整树快照、按最后修改时间 LWW
- 触发时机：数据变更约 5 秒后 / 启动后 30 秒（固定仅下载，不产生云端新版本）/ 每 15 分钟 / 手动；除手动与数据变更触发外均为仅下载，自动上传仅发生在开启"自动双向"时
- **云端快照管理**：设置页折叠面板列出各设备的加密快照，可单独删除或清空（删除后该设备被吊销，需重新配置）
- 服务端部署见 `worker/README.md`（`wrangler deploy` 三条命令；与 onetap 版 D1 Sync Worker 通用，可共用同一实例与 D1 数据库）
- **在线网页展示**：部署后访问 `https://<worker>/view`，输入 Access Token 与加密口令即可在任意浏览器查看云端标签与书签（浏览器端解密渲染，不经服务器明文）

### 设置页(按数据栏目分区)
- 设置页按数据栏目整合:**浏览历史 / 书签 / 标签收纳 / 云同步 / 关于**,每个栏目聚合该数据的全部操作
- **浏览历史**:自动记录开关、导入 Chrome 历史、JSON 备份导出/导入、CSV 导出、存储用量与清空
- **书签**:说明与"打开书签管理"入口(书签即 Chrome 原生书签)
- **标签收纳**:OneTab 兼容的 JSON/HTML 导出与 JSON 导入、打开收纳页入口
- **云同步**:状态格(上次上传/上次下载/云端设备/合并条目/自动方向)、三个方向按钮(同步云=上传 / 同步本地=下载 / 双向同步)、自动双向开关、云端快照折叠管理、断开

| 浏览历史栏目操作 | 说明 |
|---|---|
| 导入 Chrome 历史 | 把 Chrome 现有历史并入历史记录，自动去重，可反复执行；读取分页回溯 + 并发展开，失败只跳过对应批次 |
| JSON 完整备份 | 导出全部浏览历史到浏览器默认下载目录，含 schema 版本，跨设备可恢复 |
| 导入 JSON | **合并**（保留现有、跳过重复）或 **覆盖**（清空浏览记录后导入；设置/标签收纳/书签保留本地） |
| CSV 导出 | 全部访问记录导出为表格（时间/标题/URL/域名/访问方式/收藏；UTF-8 BOM，Excel 直接打开不乱码） |
| 清空记录 | 双重确认后清空浏览记录，保留设置；标签收纳与书签不受影响 |

> 存储说明：扩展环境无法使用原生 SQLite；本扩展使用 IndexedDB（Chrome 原生键值+索引存储），配合复合索引查询为毫秒级，JSON 仅作为**备份交换格式**，不参与查询。

## 数据结构（IndexedDB: `web-history-archive`，DB v4）

| Store | 说明 | 关键字段 |
|---|---|---|
| `visits` | 每次访问一行 | urlId, websiteId, title(快照), visitedAt, transition, tabId, windowId, source, sourceVisitId |
| `urls` | 按 URL 聚合 | id(=URL), websiteId, title, firstVisitAt, lastVisitAt, visitCount, starred, starredAt |
| `websites` | 按域名(host)聚合 | id(=host), firstSeenAt, lastVisitAt, visitCount |
| `settings` | 配置 | schemaVersion, recordEnabled |
| `stashItems` | 标签收纳（OneTab 兼容树形结构） | id, type(tab/group), url/title, parentIds, childIds, label, notes, locked, rating, collapsed, pinnedCount, createDate, modifyDate |

查询走复合索引（`[visitedAt,id]`、`[websiteId,visitedAt,id]`），导入去重锚点：Chrome 历史 visit 用 `sourceVisitId`（`chrome:<visitId>` + 1 秒时间容差，支持多 profile 合并），扩展自录 visit 用 `(urlId, visitedAt, tabId, transition)`。

主地址（主域名）聚合在界面层完成（`lib/util.js` 的 `baseDomain`），处理 `www.` 前缀与常见多段后缀（`com.cn`、`co.uk` 等）。

## 长期保存建议（5～20 年）

1. **每 3～6 个月**在"数据"页导出一次 JSON 完整备份，存到网盘/移动硬盘。
2. 扩展数据存放在 Chrome 的 profile 目录里：**卸载扩展会删除其数据**；重装/换电脑用 JSON 备份恢复。
3. 更换浏览器（如迁移到其他 Chromium 内核浏览器）同样靠 JSON 备份迁移。

## 隐私

- 不申请任何网站访问权限（无 `host_permissions`），不注入任何网页脚本
- 浏览历史不发起任何网络请求，数据不出本机
- 标签收纳与书签仅在**用户主动配置云同步后**经端到端加密上传到自建 Worker（服务器只见密文），未配置时同样零网络请求
- 扩展默认不作用于隐身模式；如手动开启，隐身记录也会进入历史记录

## 已知限制

- 点击工具栏图标打开**历史记录浏览页**；垂直标签栏由右键图标菜单的开关控制，侧栏头部另有"历史记录"按钮
- 垂直标签栏无法隐藏 Chrome 原生顶部标签栏（扩展没有该 API），两者并存；侧栏左右位置需首次手动移动一次
- 标题在导航瞬间可能尚未解析完成，页面加载完成后自动回填
- 标签页归属（tabId）是尽力而为的辅助信息；后台预渲染等无标签页场景记为空
- 全文搜索为"包含匹配"扫描，超大时间范围搜索会限制扫描量（界面有提示），建议配合时间/域名筛选
- 主域名聚合基于内置后缀表近似处理，个别罕见多段后缀（如某些国家域名）可能分组到二级域

background/           service worker：实时记录访问

tools/make-icons.ps1  重新生成图标（PowerShell + System.Drawing）
tools/check-imports.mjs  静态校验 import/export 一致性

修改代码后在 `chrome://extensions` 点击扩展卡片上的 **刷新** 按钮即可生效。
